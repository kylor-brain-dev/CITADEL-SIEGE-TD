# Citadel: Frontline

Fresh tower-defense game foundation. It does not modify the previous Citadel Siege TD project.

## Included
- polished responsive command UI
- persistent accounts and save/load
- Ranger and Cannon troops
- enemy variety: runners, brutes, invisible Wraiths, healers, splitters, summoners and elites
- Kendrick the Drake Champion
- Spirit Devourer Champion
- Spirit Devourer soul meter framework, Suffocation Aura, Idle Transfiguration and Puppeteer
- Champion Mastery 1,000 baseline
- Champion summon/reveal presentation
- battle waves, speed, pause, deployment, splash and status mechanics
- codex, collection, daily objective and world-threat framework

## Run
npm install
npm start

Then open http://localhost:8080
